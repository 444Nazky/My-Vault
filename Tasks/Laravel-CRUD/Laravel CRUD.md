# Laravel CRUD

## Overview
Complete guide to Laravel CRUD operations.

## Components
- Model: Database interaction
- Controller: Business logic
- Views: User interface
- Routes: URL mapping

## File Structure
```
app/
├── Http/Controllers/
│   └── ItemController.php
├── Models/
│   └── Item.php
└── Database/Migrations/
database/migrations/xxx_create_items_table.php
resources/views/items/
routes/web.php
```

## CRUD Operations
- Create: Store new records
- Read: Retrieve data
- Update: Modify existing records
- Delete: Remove records
