# System Requirements

## Overview
System requirements and specifications for cybersecurity environments.

## Minimum Requirements

### For Basic Testing
- CPU: 2 cores
- RAM: 4GB
- Storage: 50GB
- Network: Ethernet + WiFi

### For Full Lab
- CPU: 4+ cores
- RAM: 8GB+
- Storage: 100GB+
- Network: Multiple interfaces

## Recommended Hardware

### Laptop/Desktop
- CPU: Intel i5/i7 or AMD Ryzen 5/7
- RAM: 16GB+
- Storage: 256GB+ SSD
- GPU: Optional (for password cracking)

### Network Equipment
- Managed switch
- Access point
- USB WiFi adapter (monitor mode capable)
- Ethernet cables

## Software Requirements

### Operating System
- Kali Linux
- BlackArch
- Parrot OS
- Arch Linux (custom)

### Virtualization
- VirtualBox
- VMware
- QEMU/KVM
- Docker

## Virtual Machine Setup

### Resources Per VM
| VM Type | CPU | RAM | Storage |
|---------|-----|-----|---------|
| Kali | 2 | 4GB | 50GB |
| DVWA | 1 | 1GB | 20GB |
| Metasploitable | 1 | 1GB | 10GB |

### Network Configuration
- Host-only for isolated labs
- NAT for internet access
- Bridged for real network testing
