# Penetration Testing Requirements

## Overview
Requirements and methodology for penetration testing engagements.

## Scope Definition

### In-Scope Items
- Web applications
- Network infrastructure
- Mobile applications
- Internal systems
- Social engineering

### Out-of-Scope Items
- DoS testing (unless requested)
- Physical security
- Social media accounts
- Third-party services

## Legal Requirements

### Authorization
- Written authorization required
- Rules of engagement
- Timeline defined
- Contact information

### NDA
- Non-disclosure agreement
- Data handling procedures
- Report distribution limits

## Methodology

### Phase 1: Reconnaissance
- Passive information gathering
- Active scanning
- Enumeration

### Phase 2: Vulnerability Assessment
- Automated scanning
- Manual testing
- Documentation

### Phase 3: Exploitation
- Targeted attacks
- Proof of concept
- Access persistence

### Phase 4: Post-Exploitation
- Privilege escalation
- Data access
- Lateral movement

### Phase 5: Reporting
- Executive summary
- Technical findings
- Remediation recommendations

## Documentation

### Pre-Engagement
- Scope document
- Rules of engagement
- Authorization letters
- NDA

### During Engagement
- Screenshots
- Command outputs
- Network captures
- Notes

### Final Report
- Executive summary
- Methodology
- Findings (CVSS scored)
- Remediation steps
- Appendix

## Deliverables

### Reports
- Preliminary findings
- Final report
- Presentation

### Artifacts
- Raw logs
- Screenshots
- Exploit code (if applicable)
