# OSINT Basics Notes

Standalone note. No links in or out. Passive methods only unless scoped.

## Domains and Certs

- crt.sh for certificate transparency history.
- DNS dumpster and securitytrails for records.
- Sublist3r or amass for subdomain enumeration.

## People and Accounts

- Username search across breach dumps and socials.
- theHarvester for emails, hosts, and virtual hosts.
- Exif data on published photos for locations and devices.

## Code and Leaks

- GitHub dorks for keys, tokens, and internal URLs.
- GrayHatWarfare for exposed buckets.
- Paste sites and combo lists for credential reuse checks.

## Infrastructure

- Shodan and censys for exposed services and banners.
- BuiltWith and Wappalyzer for stack fingerprinting.
- WHOIS history for registrar and name server changes.

## Opsec Rules

- Use sock puppets, never personal accounts.
- Log every query with date for the report.
- Stop at collection, no interaction with targets.

## Gotchas

- Stale data misleads, corroborate across two sources minimum.
- Screenshots beat copied text for evidence.
- Respect scope even in passive work, some sources log viewers.
