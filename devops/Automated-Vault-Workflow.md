# Automated Vault Workflow

> Standalone reference. No links in or out. Embed-only.

## Flow

1. Edit notes in Obsidian
2. Plugin auto-commits changes to git
3. Push syncs the vault to GitHub
4. Pull on other devices keeps them in sync
