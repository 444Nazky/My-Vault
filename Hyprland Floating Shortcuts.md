# Hyprland Floating Window Shortcuts

## Toggle Floating Mode

| Action | Shortcut |
|--------|----------|
| Toggle floating for active window | `SUPER + A` |

## Move & Resize Floating Windows

| Action | Shortcut |
|--------|----------|
| Move floating window (drag) | `SUPER + Z` |
| Resize floating window (drag) | `SUPER + X` |

> **Note:** After enabling floating mode with `SUPER + A`, drag the window with `SUPER + Z` or resize with `SUPER + X`.

## Other Floating Controls

| Action | Shortcut |
|--------|----------|
| Pin window (stay on all workspaces) | `SUPER + P` |
| Picture-in-Picture mode | `SUPER + ALT + Backslash` |
| Center window | `CTRL + SUPER + Backslash` |
| Normalize window (resize + center) | `CTRL + SUPER + ALT + Backslash` |
