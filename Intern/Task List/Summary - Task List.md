# Summary - Task List Magang Software Engineer (Web Monitoring Ponton)

## Informasi Umum

- **Program:** Magang Software Engineer selama 24 minggu
- **Proyek:** Web Monitoring Ponton (IT-DEV Karyamas Plantation)
- **Peserta:** Norutama Nourt Khar Rocky
- **Target Akhir:** Aplikasi dapat digunakan oleh pengguna secara langsung dan dapat dioperasikan secara mandiri oleh tim melalui dokumentasi yang lengkap

---

## Tahapan Program & Target Utama

### 1. Infrastruktur

- Menyiapkan Server Ubuntu, web server, Docker Engine dan Compose, serta MariaDB
- Melakukan pengaturan jaringan, keamanan (firewall, SSH key), backup, dan verifikasi restorasi sistem

### 2. Tools Development

- Menyiapkan Git, VS Code, editor, serta ekstensi bahasa dan framework yang dibutuhkan
- Membentuk alur kerja development (branching, commit, pull request, code review) serta debugging aplikasi

### 3. Deployment

- Mempersiapkan server staging dan production, menyusun stack Docker, serta memindahkan data aplikasi
- Melakukan pengujian fungsional, pengujian keamanan, User Acceptance Testing (UAT) bersama perwakilan pengguna, hingga proses go-live (deployment akhir)

### 4. Monitoring & Operasional

- Memantau ketersediaan server, performa aplikasi, manajemen log, serta pengaturan alerting dan eskalasi insiden
- Melakukan simulasi pemulihan bencana (restore), evaluasi performa, simulasi penanganan gangguan, hingga tahap serah terima (handover) dan dokumentasi akhir

---

## Ketentuan & Rutinitas Penting

### Penggunaan Data

- Pengembangan dilakukan menggunakan data contoh atau data yang disamarkan
- Perubahan produksi atau migrasi database wajib melalui persetujuan mentor

### Rutinitas Pasca Go-Live

- **Harian:** Memeriksa ketersediaan aplikasi, alert, kapasitas disk, dan hasil backup
- **Mingguan:** Meninjau tren performa, merangkum insiden, serta memperbarui daftar tugas
- **Bulanan:** Menguji restore data, evaluasi retensi log, dan pemeliharaan dependency
