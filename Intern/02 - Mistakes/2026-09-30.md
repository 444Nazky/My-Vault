# 02 - Mistakes

## 2026-09-30

### Admin Dashboard JSX Structure Broken

**Mistake:** Saat edit `AdminDashboard.tsx`, struktur JSX tidak properly closed.

**What happened:**
- Opening `<div className="flex min-h-screen bg-slate-50">` tidak ditutup
- Sidebar div tidak properly wrapped

**Lesson:** Periksa struktur bracket/div saat edit React components. Gunakan Prettier/ESLint untuk auto-format.

**Fix:** Tambah closing `</div>` yang missing.

---

### PHP Server Router Not Used

**Mistake:** Server PHP dijalankan dengan `-t admin-ci` yang tidak menggunakan `index.php` sebagai router.

**What happened:**
- `index.php` injects `data-admin` attribute ke `<html>`
- Tanpa router, browser dapat HTML tanpa `data-admin`
- `isAdminHost()` returns `false` → blank screen

**Lesson:** Untuk aplikasi yang butuh preprocessing PHP, harus gunakan router (`php -S localhost:8000 admin-ci/index.php`), bukan document root (`-t admin-ci`).
