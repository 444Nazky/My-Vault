## Koreksi status update (penting)
- “Update berhasil ditarik, tapi belum ada perubahan” paling sering disebabkan oleh:
  - cache/service worker atau penyimpanan internal yang masih menyajikan bundle lama,
  - state OTA basi (`trip.ota.state` / `trip.ota.currentVersion`) yang masih mengarah ke versi lama,
  - atau reload/service-worker skip waiting tidak berhasil.
- Jika perangkat terlihat “update berhasil” tapi isinya tidak berubah, lakukan:
  - paksa hard reload,
  - cek DevTools → Application → Cache Storage / Service Workers / IndexedDB/localStorage,
  - atau jalankan reset OTA via fitur “Reset Update” bila tersedia.

## Langkah diagnostik DevTools (OTA / cache bundle)
1. Buka DevTools → **Application → Service Workers**.
   - Pastikan SW terdaftar dan tidak stuck di `waiting`.
   - Coba “Update on reload” / “Skip waiting” sesuai kondisi.
2. DevTools → **Application → Cache Storage**.
   - Cari cache bernama `trip-ota-active` atau `trip-ota-*`.
   - Jika isinya masih bundle lama, hapus cache tersebut lalu reload.
3. DevTools → **Application → Local Storage** (origin app).
   - Cek kunci:
     - `trip.ota.state`,
     - `trip.ota.currentVersion`,
     - `trip.ota.persistActive`,
     - `trip.ota.lastError`.
   - Jika `trip.ota.currentVersion` masih versi lama padahal manifiest baru sudah diunduh, itu gejala state OTA macet.
4. DevTools → **Network**.
   - Filter request ke `version.json` dan aset `assets/...` (mobile branch) atau aset root (main branch).
   - Pastikan tidak ada respons `304 / cached` yang masih mengarah ke versi lama saat cek update.
5. Jika di perangkat Android/Capacitor:
   - Pastikan bundle web yang dipakai dari `assets/public` hasil `npx cap sync android` terbaru.
   - Jika ragu, uninstall → install ulang APK debug dari output terbaru, atau pakai fitur Reset Update bila tersedia.
