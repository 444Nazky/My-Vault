# Sesi 2 — Modal Geofence UX, Re-audit Dependency, & Perbaikan Vitest

## 1. Penyempurnaan UI/UX Modal Titik Geofence (Admin Dashboard, Halaman Master Rute)

Semua perubahan di `Trip-Dashboard Admin Branch/src/pages/admin/tabs/RoutesTab.tsx` (satu-satunya file yang diedit):

1. **Auto-extract link Google Maps**: input link kini punya `onPaste` (intersep clipboard) + `onChange` → parser jalan otomatis tanpa tombol.
   - URL penuh (peatern `@lat,lng`, `q=`, `lat=`, dll. — `parseMapsUrl`) → sinkron, terisi seketika.
   - Short link (`maps.app.goo.gl`, `goo.gl`) → async `resolveMapsShortLink` (follow redirect) lalu parse; tombol "Isi Otomatis" tetap ada sebagai fallback, label jadi "Memproses…" saat resolving.
2. **Latitude & Longitude read-only**: keduanya jadi `readOnly disabled` + background abu-abu (`bg-slate-100`/`bg-slate-50`) + badge hijau **"✓ Terisi Otomatis"** di label — admin tak bisa salah ketik koordinat.
3. **Default smart radius 100m**: saat link berhasil diparse, radius diisi 100 jika field kosong (tidak menimpa nilai yang sudah diedit admin). Helper text baru: *"Radius aman zona geofence untuk pengukuran jarak akurat di aplikasi mobile."* + atribut `min=1 max=10000 step=1`.
4. **Sinkronisasi submit**: `saveGeofencePoint` kini `Number.parseFloat` + `Number.isFinite`, validasi rentang (lat ±90, lng ±180, radius 1–10000) → API menerima `latitude`/`longitude`/`radiusMeters` sebagai **number** murni, bukan string.

State baru `coordsFromLink` memegang status "terisi dari link" dan direset di `startAddGeofence`/`startEditGeofence`/`cancelGeofenceEdit`.

## 3. Kesalahan Ditemukan Saat Menjalankan Test Suite

Let penuh di [[02 - Mistakes/Menghapus @capacitor/http Memutus Lazy Import yang Tak Terdeteksi Build]].

**Yang terjadi**: `npm run test:unit` mobile-trip semula 4 pass / `ota.test.ts` gagal load — `ota.ts` masih `await import('@capacitor/http')` (lazy), padahal paket sudah dihapus. Lolos `tsc` dan `ng build` karena dynamic import terbungkus try/catch; **Vite/vitest menolak di fase resolusi modul sebelum catch jalan**.

**Fix**: impor `CapacitorHttp` langsung dari `@capacitor/core` (hasil merger) — fallback `fetch` di web tetap utuh, interface `nativeFetch()` tidak berubah.

**Pelajaran**: grep saat menghapus dep harus mencakup pola **dynamic import** (`import('x')`), bukan hanya `from 'x'`; dan `tsc + build` bukan gate cukup — test suite yang membuka module graph penuh adalah gate ketiga.
