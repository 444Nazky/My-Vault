# Sistem Informasi Angkutan Plantation

> **Status:** Final — 25 September 2026

## Tujuan
Digitalisasi pencatatan kendaraan Angkutan di kawasan perkebunan.

## Komponen

| Komponen | Teknologi |
|----------|-----------|
| Mobile App | Ionic + React + Tailwind |
| Admin Dashboard | React (build statis, disajikan CodeIgniter) |
| Backend API | Node.js + Express |
| Database | SQLite (sql.js) |
| Auth | JWT (HS256, 24 jam) |
