## Quick Start

### Claude Code (Current Session)
```bash
claude
```

### Grok
```bash
grok "your question"
```

### Gemini CLI
```bash
gemini "your prompt"
```

### OpenCode
```bash
opencode
```

### FreeBuff
```bash
freebuff
```

### Kilo
```bash
kilo
```

### Hermes
```bash
hermes
hermes update
```

### Ollama (Local Models)
```bash
ollama serve
ollama run llama3.2
```
